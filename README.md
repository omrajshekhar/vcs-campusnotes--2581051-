# CampusNotes

A simple project for organizing campus notes.

## Organization

Keep notes grouped by course, then by topic. Add key concepts, examples, and questions to review.

## Exam Review

Before each exam, review the notes for each course and list topics that need more practice.


## Contributing

Use a feature branch for changes and open a pull request for review.
